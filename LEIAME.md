# Assistente de Tablet

App Android simples (Kotlin) com:
- relógio grande e data
- calendário do mês completo (◀ ▶ para mudar de mês, "Hoje" para voltar)
- agenda por voz ("criar agenda amanhã às 10 horas dentista")
- lanterna por voz ("acender lanterna" / "apagar lanterna")
- lembretes: toca um alarme e mostra um aviso na hora do compromisso
- comandos de luz (ainda sem conexão com lâmpadas: próxima etapa)

## Como gerar o APK pelo GitHub (resumo)
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta.
3. Aba "Actions" -> espere o "Compilar APK" ficar verde.
4. Baixe "assistente-tablet-apk", extraia o zip e instale o app-debug.apk no tablet.
